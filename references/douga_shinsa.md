# 動画で見る審査（作っとらん係に完成品だけ見せる・2026-10-18）

元＝huashu-art-motion「独立审片」（MIT・未承認）。今までの審査はコマ一覧（0.5秒ごとの静止画）だけ＝なめらかさと音が見えてへんかった（jiko_hyoka_20261012.md の10番）。
材料＝`python3 scripts/shinsa_zairyo.py <完成.mp4> --work <作業>` → `審査_材料/`（0.25秒ごとのタイル・動きの曲線 ugoki.csv・音の出だしと絵の切れ目の差 oto.csv）。

## 係への頼み方（この文をそのまま渡す。台本・設計表・作った会話は渡さん）
```
あなたはこの動画の制作に一切関わっていない審査係。渡すのは完成品の mp4 と 審査_材料/ だけ。
1. 審査_材料/tiles_*.jpg を時刻順に全部見る（1枚＝4秒・0.25秒ごと16コマ）。
2. ugoki.csv で、違いが急に跳ねる所（前後の3倍以上）と、ほぼ0が1秒以上続く所を探し、そのタイルを見に行く。
3. oto.csv で、絵の出来事（切れ目・動きの山）に一番近い音が ±80ms 以上ずれとる所を探す（音と絵が合ってない候補。動きの山は0.25秒刻みなので±125msは誤差）。
4. 必要なら mp4 から ffmpeg でその前後を 0.04秒ごとに抜いて確かめる。
5. 見る観点：①字が切れる・重なる・読めん速さ ②何も起きん・急に跳ぶ・寄って戻る往復 ③主役が分からん・目が迷う ④物の形が崩れる・刺さる・浮く ⑤音と動きのずれ ⑥40代が一目で分かるか ⑦安っぽい・AIっぽい所
6. 書く物：表（時刻｜重さ 高/中/低｜何が起きとる｜直し方）を最大10行＋10点満点の点＋一言。前回の審査がある時は「前の指摘の再発」と「新しい指摘」を分ける。
7. 置き場：<作業>/審査/<YYYYMMDD_HHMM>.md（nouhin_gate.py はこのファイルが無いと赤）
```

## 回し方
- 係＝サブエージェント（Sonnet でよい）。長い動画（60秒超）は2人に分けて前半・後半。
- 直すのは「高」から。直したら書き出し→もう1周（最大3周）。点は 8 以上で見せる（届かん時は「未達・何点」と報告）。
- 🔴 静止画を抜いて見る審査は、カメラのなめらかさは完全には分からん。**見せる前に自分で1回、普通の速さで通して見る**（QuickTime）。
